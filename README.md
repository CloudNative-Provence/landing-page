# Cloud Native Provence

The KCD Provence conference site, available in French and English.

Visit [cloudnative-provence.fr](https://cloudnative-provence.fr) to browse the programme,
save and share your agenda, find rooms on the venue map, and plan your visit.
Use the language selector to switch between French and English.

- [Programme, saved agenda, and venue map guide](docs/usage/program-and-map.md)
- [Documentation](docs/README.md)
