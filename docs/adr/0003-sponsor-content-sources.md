# ADR 0003: Sponsor description sources

Status: Accepted (retrospective record)

Recorded: 2026-10-22

## Context

The sponsor registry includes French and English descriptions of Dell Technologies as Monaco Digital's co-sponsor. The sponsor asset readme recorded their sources and the consultation date. This ADR preserves that evidence separately from the current content guide.

## Decision

Use concise summaries of Dell's official infrastructure and container information for the bilingual descriptions. Keep the copy in the sponsor registry and dated source evidence in this ADR.

## Evidence

The previous sponsor readme records consultation of these pages on **2026-10-21**:

- [Dell IT infrastructure solutions](https://www.dell.com/fr-fr/learn/it-infrastructure/lp/solutions)
- [Dell Kubernetes and containers](https://www.dell.com/fr-fr/lp/workloads-kubernetes-containers)

This is preserved historical evidence, not a new verification of those pages.

## Alternative

Keeping dated source evidence in the asset readme would mix editorial history with
current asset instructions. This record keeps that evidence accessible from the content guide.

## Consequences

The [content guide](../development/content.md#sponsors) describes the editing workflow. Recheck the relevant sources when changing factual claims and record new dated evidence in an ADR.
