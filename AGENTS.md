# Repository instructions

- Read the [documentation policy](docs/development/documentation.md) before changing code or documentation. It applies to every change.
- Use the [documentation index](docs/README.md) to find the canonical guide. Contributor setup and validation are in [getting started](docs/development/getting-started.md).
- Verify documented behavior against current source and configuration. Update affected guides, examples, links, and validation in the same change.
- Keep root readme files focused on end users. Put detailed user guides in `docs/usage/`, contributor guides in `docs/development/`, and decision history in `docs/adr/`.
- Do not hand-edit autogenerated `.github/actions/**/README.md` or `.github/workflows/**/README.md`. Follow the documentation policy for source changes and generation.
- Run focused validation for the change and report only checks actually completed.
