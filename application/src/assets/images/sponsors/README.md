# Sponsor assets

Only sponsors in the supplied 2026 roster are displayed. Tier assignments and site links live in `domains/event/sponsors/sponsors.ts`.

A joint sponsorship uses the optional `coSponsor` name, logo, localized pitch, and website URL. Both brands appear together on the card and in the dialog, and count as one sponsorship in their shared tier. The dialog and no-JavaScript fallback show each company's description and website link separately.

Cards stay compact with a single action: “Découvrir [sponsor]” / “Discover [sponsor]” opens the complete localized pitch in a native dialog, which includes the sponsor’s site link. Every sponsor must have a pitch in French and English; the `Sponsor` type requires both. Without JavaScript, pitches and site links remain available in expandable details.

Dell Technologies' French and English descriptions summarize its official [IT infrastructure solutions](https://www.dell.com/fr-fr/learn/it-infrastructure/lp/solutions) and [Kubernetes and containers](https://www.dell.com/fr-fr/lp/workloads-kubernetes-containers) pages, consulted on 2026-10-21.
